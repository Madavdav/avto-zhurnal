# АвтоЖурнал

Личный учёт заправок, расхода топлива и расходов для нескольких автомобилей. Работает как обычный сайт и как приложение на iPhone: без аккаунтов и рекламы, с локальным распознаванием фото заправки и офлайн-режимом после первого открытия.

![АвтоЖурнал](icons/icon-512.png)

## Что умеет

- Ведёт отдельные журналы для разных машин: личной, рабочей или любой другой.
- Позволяет быстро переключать автомобиль по названию в верхней панели.
- Для каждого профиля хранит свой начальный пробег, заправки, обслуживание, расходы, графики и статистику по АЗС.
- Считает текущий пробег по последней записи, средний расход, расходы на топливо и стоимость топлива на километр — отдельно за текущий месяц или за всё время.
- Показывает сумму, литры и среднюю цену за выбранный период: всё время, этот месяц, прошлый месяц, последние 30 дней или этот год.
- Требует указать новый пробег при добавлении заправки: пустое поле и пробег, совпадающий с предыдущей записью, не сохраняются. Автоматически подставленное старое значение считается только подсказкой.
- Подсказывает полный пробег по последним трём цифрам и предупреждает, если новый пробег меньше предыдущего, но не мешает исправлять старые записи.
- Позволяет выбрать один из двух типов топлива: **Солярка (дизель)** или **Бензин АИ-95**. Старым записям тип не назначается наугад.
- Запоминает последнюю введённую цену отдельно для дизеля и АИ-95 и подставляет её при выборе типа в новой заправке. Цены корпоративных заправок через **דלקן** для этого не используются.
- Позволяет выбрать АЗС из списка: **Paz, Sonol, Dor Alon, Delek** или **«Другое»** со своим названием.
- Показывает статистику по АЗС: где вы заправляетесь чаще всего, где уходит больше денег, а также сумму, литры и среднюю цену по каждой заправке.
- Автоматически пересчитывает стоимость заправки: по литрам и цене за литр, либо по литрам и общей сумме.
- Распознаёт данные заправки по фото: литры, цену за литр и сумму. Фото обрабатывается прямо в браузере и никуда не отправляется, а перед сохранением всегда показывается экран проверки.
- Считает расход по методу «от полного до полного». Частичные заправки не портят результат.
- Хранит журнал заправок с редактированием и удалением.
- Удерживает клавиатурный фокус внутри открытого диалога, объявляет его диалогом для скринридера и возвращает фокус на кнопку, которая его открыла. Это работает для заправки, обслуживания, профилей, проверки фото и подтверждений, в том числе когда один диалог открыт поверх другого.
- Ведёт отдельный журнал обслуживания и ремонта: произвольное название работы, дата, пробег, стоимость запчастей и работ.
- Показывает общие расходы на обслуживание отдельно от топлива: на главной и в разделе **«Сервис»**.
- Показывает график расхода и расходов по месяцам.
- Сохраняет данные на устройстве и умеет делать резервную копию в JSON вместе с профилями автомобилей, обслуживанием и названиями АЗС.
- Не сообщает об успешном сохранении, если запись не удалась: при ошибке данные остаются прежними, а пользователь видит понятное сообщение.
- Перед импортом и удалением всех данных автоматически создаёт страховочную копию. Если копию создать не удалось, опасное действие отменяется.
- Проверяет импортируемый файл: даты, пробег, литры, цены, суммы, названия работ, стоимость обслуживания и уникальность идентификаторов.
- Работает офлайн после первого открытия, включая локальный OCR-движок.
- Поддерживает светлую, тёмную и системную тему. Выбор темы хранится отдельно от журнала и не попадает в резервную копию.
- Оптимизирован для телефона в портретной и альбомной ориентации: крупный пробег, быстрые действия, компактные показатели и удобная нижняя навигация.
- Не отправляет фото и записи на сторонние серверы, не использует платные API, аккаунты или облачные базы данных.

Валюта — израильские шекели (₪).

## Как запустить на компьютере

1. Откройте папку `murano-log` (внутреннее имя папки оставлено прежним, чтобы не ломать существующие ссылки).
2. Дважды щёлкните `start-server.cmd`.
3. Откройте в браузере: **http://localhost:8080/**
4. Чтобы остановить сервер, нажмите `Ctrl+C` в чёрном окне.

Сервер нужен только для проверки приложения так, как оно будет работать на телефоне. Он работает только на вашем компьютере (`127.0.0.1`) и не выходит в интернет. Node.js, Python и что-либо ещё устанавливать не нужно.

Если порт 8080 занят, запустите в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-server.ps1 -Port 8081
```

и откройте `http://localhost:8081/`.

В конце должно быть зелёное «Все тесты пройдены».

## Автомобили

У каждого автомобиля отдельный профиль. Переключение не смешивает данные: заправки, начальный пробег, графики и статистика остаются у своей машины.

- **Сменить автомобиль** — нажмите на название машины под надписью «АвтоЖурнал» в верхней панели.
- **Добавить автомобиль** — в открывшемся списке нажмите «+ Добавить автомобиль», укажите название и, при желании, начальный пробег.
- **Переименовать или изменить пробег** — откройте **Настройки → Автомобиль** и сохраните изменения.
- **Удалить автомобиль** — в списке профилей нажмите значок корзины. Удалить можно только один из нескольких профилей; последний остаётся всегда.

Новый профиль начинается с пустого журнала. Начальный пробег можно не указывать — тогда он появится после первой заправки или когда вы введёте его в настройках.

Старые данные автоматически переносятся в первый профиль «Моя машина» при первом открытии новой версии. Старые резервные копии тоже можно импортировать.

## Как пользоваться

1. Выберите нужный автомобиль в верхней панели.
2. Один раз проверьте начальный пробег в **Настройках → Автомобиль**. Для существующего профиля сохранится прежнее значение; для нового его можно оставить пустым.
3. Нажмите большую кнопку **+** и добавьте заправку.
4. Укажите **новый пробег**. Число, которое приложение подставило из прошлой заправки, — только подсказка: его нужно заменить. Пустой пробег и пробег, равный предыдущей записи, сохранить нельзя. Если ввести только последние три цифры, приложение предложит полный пробег — останется нажать «Подставить».
5. Выберите тип топлива: **Солярка (дизель)** или **Бензин АИ-95**. Для нового типа цена подставится из памяти, если вы уже вводили её раньше.
6. Укажите литры, затем заполните **цену за литр** или **общую сумму**. При необходимости нажмите **«Фото»** и распознайте чек или табло — значения сначала появятся на экране проверки.
7. Выберите АЗС. Если её нет в списке, выберите **«Другое»** и введите название.
8. Отметьте «Заправка до полного», если залили полный бак. Если это корпоративная заправка через **דלקן**, включите отдельный переключатель.
9. Сохраните.

Расход появится после **двух** заправок «до полного». Частичные заправки можно добавлять спокойно: их литры будут учтены в следующем полном баке.

При редактировании старой записи проверка «нового» пробега не блокирует исправление: можно уменьшить значение, исправить дату или ошибку. Старой записи без типа топлива можно оставить пустой тип — приложение не назначает его наугад.

### Как работает автопересчёт

Приложение запоминает, какое поле вы редактировали последним — цену за литр или общую сумму.

- Ввели литры и цену за литр → сумма = литры × цена.
- Ввели литры и общую сумму → цена = сумма ÷ литры.
- Потом изменили литры → приложение пересчитывает **противоположное** поле от того, которое вы редактировали последним.
- Пустые поля, ноль литров и отрицательные числа не приводят к делению на ноль и не создают `NaN`/`Infinity`.
- Внутри значения хранятся точно. На экране сумма показывается с двумя знаками после запятой.

Пример: `40 л × 3,19 ₪ = 127,60 ₪`. Если вместо цены ввести `150 ₪` за `50 л`, приложение покажет `3,00 ₪/л`. Если затем поменять литры на `60`, цена станет `2,50 ₪/л`, потому что последней редактировалась сумма.

### Распознавание по фото

В форме заправки есть две кнопки: выбрать готовое фото из галереи или сделать снимок камерой. Фото уменьшается и обрабатывается **в браузере** с помощью локального движка Tesseract.js. Оно не загружается на сайт, не уходит в облако и не попадает в резервную копию.

1. Нажмите **«Фото»** и выберите снимок чека, табло колонки или экрана оплаты.
2. Дождитесь окончания распознавания. Можно отменить его, если фото выбрано случайно.
3. Проверьте литры, цену за литр и сумму на экране проверки. Числа можно исправить вручную.
4. Нажмите **«Применить»** — значения попадут в форму, но заправка ещё **не сохранится**. Отдельно нажмите **«Сохранить заправку»**.

Распознавание не считается подтверждением: всегда проверяйте числа глазами. Если текст на фото не читается или движок ошибся, просто введите данные вручную — этот способ остаётся основным. Для камеры на телефоне нужен HTTPS-адрес; на компьютере подходит `http://localhost`.

### Топливо и последняя цена

В журнале ровно два типа топлива:

- **Солярка (дизель)**
- **Бензин АИ-95**

Тип обязателен для новой заправки и показывается в истории отдельной меткой. Цена запоминается отдельно для каждого типа: если последняя личная заправка дизеля была по `7,77 ₪/л`, то при выборе дизеля подставится `7,77`, а для АИ-95 — его собственная последняя цена. Если цена для выбранного типа ещё не вводилась, поле остаётся пустым.

Последняя цена обновляется только когда вы действительно ввели или подтвердили цену за литр. Если заполнить только общую сумму, цена для следующей заправки не запоминается. Замена литров или исправление старой записи не меняет цену в памяти автоматически.

Если включить **«Корпоративная заправка (דלקן)»**, цена этой записи не станет последней ценой для личных заправок. Текст `דלקן` в заметке или названии АЗС тоже распознаётся как корпоративная заправка. АЗС **Delek** — это обычная сеть, а не דלקן; она не включает этот признак.

### Итоги и статистика

На главном экране видно пробег из **последней по дате заправки**, а не максимальное значение. Если старую ошибочную запись исправили, главный экран покажет исправленный последний пробег.

Переключатель **«Этот месяц / Всё время»** меняет два показателя:

- **Расходы на топливо** — сумма заправок за выбранный период.
- **Топливо, ₪/км** — только стоимость топлива на километр, без обслуживания, страховки и других расходов владения.

Карточка **«Всего на топливо»** показывает затраты на заправки за всё время, а карточка **«Обслуживание»** — общие расходы на ремонт и сервис за всё время. Эти суммы не смешиваются.

Для текущего месяца километры считаются от последней заправки перед началом месяца. Для «Всего времени» — от начального пробега в настройках. Если опорного пробега нет или одометр не вырос, вместо стоимости показывается «—» и подсказка, каких данных не хватает. Случайная цифра не подставляется.

В разделе **«Статистика»** можно выбрать период. Для него показываются:

- общая сумма, литры и средняя цена литра;
- АЗС, где вы заправлялись чаще всего;
- АЗС, на которую ушло больше всего денег;
- список всех АЗС с количеством заправок, литрами и суммой.

Названия из списка (`Paz`, `Sonol`, `Dor Alon`, `Delek`) сравниваются как одна АЗС независимо от регистра. Для «Другое» сохраняется введённое название, например `Yango`.

## Обслуживание и ремонт

В нижнем меню откройте **«Сервис»**. Здесь ведётся отдельный журнал обслуживания выбранного автомобиля.

1. Нажмите **+** и укажите дату, пробег и название работы или события. Название можно писать свободно: «Замена масла», «Шиномонтаж», «Страховка», «Диагностика» — списка категорий нет.
2. Заполните стоимость запчастей и работ. Любое из полей можно оставить пустым или нулевым. Итог по записи считается автоматически.
3. При желании добавьте заметку: какие детали использовались, где выполнялась работа и т. п.
4. Сохраните. Запись появится в истории; итог раздела и карточка на главной обновятся сразу.

Записи можно редактировать и удалять. После изменения или удаления общая сумма, суммы по запчастям и работам пересчитываются автоматически. История сортируется по дате: сначала новые записи.

Обслуживание хранится отдельно для каждого профиля автомобиля. Переключение машины меняет и журнал обслуживания, и его итоги. В резервную копию входят все записи обслуживания.

## Данные и резервные копии

Данные лежат в `localStorage` браузера — только на этом устройстве. Они не отправляются в интернет. Профили автомобилей, заправки, обслуживание, названия и идентификаторы АЗС тоже сохраняются в резервной копии.

Важно: если очистить данные браузера, удалить приложение или освободить место на iPhone, Safari может удалить локальные данные. Поэтому раз в месяц делайте резервную копию:

- **Настройки → Экспортировать данные** — скачается файл `avto-zhurnal-ГГГГ-ММ-ДД-ЧЧ-ММ-СС.json` со всеми автомобилями.
- **Настройки → Импортировать из файла** — заменит текущие данные содержимым файла. Старые файлы `murano-log-...json` тоже поддерживаются.

Перед импортом приложение проверяет файл и создаёт автоматическую страховочную копию в браузере. Если проверка или создание копии не удались, текущие данные не меняются. Перед удалением всех данных копия тоже создаётся автоматически. Восстановить последнюю копию можно кнопкой **Настройки → Восстановить последнюю копию**.

Импорт отклоняет будущие даты, нулевой пробег, нулевые или отрицательные цены и суммы, пустые названия работ, отрицательную стоимость запчастей или работ, а также повторяющиеся идентификаторы записей. Это защищает журнал от повреждённых файлов. После успешного импорта открывается автомобиль, который был активным в резервной копии. Старые копии без раздела обслуживания открываются как обычно — журнал обслуживания в них просто пустой.

## Можно ли пользоваться на iPhone

Да, но есть важное условие: приложение должно быть открыто по адресу **HTTPS**. Локальный `http://localhost:8080/` работает только на компьютере. Открыть его на iPhone по Wi-Fi обычно нельзя, а по HTTP-адресу компьютера Safari не даст установить приложение и не включит офлайн-режим.

Самый простой бесплатный путь:

1. Разместить папку `murano-log` на статическом хостинге: GitHub Pages, Cloudflare Pages или Netlify Drop.
2. Открыть полученный HTTPS-адрес в Safari на iPhone.
3. Нажать «Поделиться» → **«На экран Домой»** → **«Добавить»**.

Отдельный сервер, база данных, аккаунт или платный API не нужны. Всё хранится в браузере телефона в `localStorage`, поэтому:

- на компьютере и на iPhone будут **разные** данные;
- данные не синхронизируются между устройствами автоматически;
- резервная копия JSON — основной способ перенести записи или восстановить их.

Для личного учёта автономного хранения в браузере достаточно. Но если вы почистите Safari, удалите приложение или телефон потеряется, без резервной копии данные пропадут.

## Установка на iPhone

После размещения на HTTPS:

1. Откройте адрес приложения в **Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран Домой»**.
4. Нажмите **«Добавить»**.

Приложение откроется без адресной строки, со своей иконкой и будет работать офлайн.

При выходе новой версии приложение проверяет обновление при запуске и возврате в него. Страницы, код и стили загружаются сначала из сети, поэтому обновление не застревает в старом кэше. Если новая версия уже готова во время работы, приложение предложит перезапустить его.

## Ограничения

- Начальный пробег — стартовая точка учёта, а не замена одометра. Его можно исправить в любой момент.
- Топливо, ₪/км — справочная оценка только топливных расходов, а не полная стоимость владения автомобилем и не бухгалтерский расчёт.
- Приложение не подключается к автомобилю и не заменяет бортовой компьютер.
- Распознавание по фото ошибается на бликах, наклоне, мелком шрифте и нестандартных чеках. Оно только помогает заполнить форму, поэтому экран проверки обязателен. Для съёмки на iPhone нужен HTTPS, а на старых устройствах обработка может занять несколько секунд.
- Локальные данные может удалить браузер или iOS. Резервная копия — ваша страховка.
- Автоматическая страховочная копия тоже хранится в `localStorage`. Если на устройстве совсем не осталось места, приложение отменит импорт или удаление и сохранит текущие данные.
